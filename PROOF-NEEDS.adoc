= PROOF-NEEDS — palimpsest-plasma
:toc: preamble

What this repository needs proved, which verifier each obligation belongs
to, and where each one stands. Verifier choices follow
https://github.com/hyperpolymath/standards/blob/main/3-practice/PROOF-POLICY.adoc[PROOF-POLICY]:
first-party Rust is verified with *Creusot* (contracts written in *Pearlite*,
Creusot's specification language) and with *Verus*, both by default (§1.2);
*Idris2* is for APIs and ABIs. Status words are the closed §5 vocabulary.

== Current state

* *Machine-checked proofs:* none. No crate has a Pearlite contract
  (`#[requires]`/`#[ensures]`) or Verus code (`verus!`).
* *Creusot:* `.github/workflows/creusot-gate.yml` calls the estate gate. With
  no contracts in the tree it reports "nothing was proved"; that is a notice,
  not assurance.
* *Verus:* no gate yet.
* *Idris2:* no ABI is exposed, so no Idris2 obligation exists today.
* *Census:* https://github.com/hyperpolymath/mathesis[mathesis] lists this
  repository with no proof files of its own, which matches the above.
* *Panic sites:* 69 `unwrap()` calls outside tests (2026-11-17).

== Obligations

default verifiers. None has a contract yet.
